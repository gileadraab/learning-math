## Day 1 Exercises: Function Fundamentals

### Basic Function Evaluation (20 problems)

**Level 1: Simple Substitution**
1. Given f(x) = 3x + 5, find:
   - f(2) = ?
   - f(-1) = ?
   - f(0) = ?
   - f(4) = ?

2. Given g(x) = x² - 4x + 1, find:
   - g(3) = ?
   - g(-2) = ?
   - g(5) = ?
   - g(0) = ?

3. Given h(t) = 2t² + 3t - 7, find:
   - h(1) = ?
   - h(-3) = ?
   - h(2) = ?
   - h(-1) = ?

**Level 2: Complex Expressions**
4. Given f(x) = √(x + 3) - 2/(x-1), find:
   - f(6) = ?
   - f(0) = ? (if defined)
   - f(-2) = ?
   - f(5) = ?

5. Given R(x) = |2x - 4| + x², find:
   - R(3) = ?
   - R(-1) = ?
   - R(0) = ?
   - R(2) = ?

**Level 3: Function Expressions**
6. If f(x) = x² + 2x + 1, find:
   - f(x + 1) = ?
   - f(2x) = ?
   - f(x²) = ?
   - f(-x) = ?

### Domain and Range Problems (15 problems)

7. Find the domain of each function:
   - f(x) = 1/(x - 3)
   - g(x) = √(x - 2)
   - h(x) = √(4 - x²)
   - k(x) = 1/√(x + 1)
   - m(x) = (x + 1)/(x² - 4)

8. Determine the domain and range:
   - f(x) = x² + 1
   - g(x) = -2x² + 8
   - h(x) = 1/x
   - k(x) = √x + 3
   - m(x) = |x - 2| + 1

9. **Word Problems**:
   - A ball is thrown upward with height h(t) = -16t² + 64t + 5. What is the domain in the context of the problem?
   - The cost function C(x) = 50 + 3x represents the cost of producing x items. What is a reasonable domain?
   - The area of a square A(s) = s² where s is the side length. What are the domain and range?

### Function Notation Practice (10 problems)

10. Given the table of values for f(x):
    | x  | -2 | -1 | 0 | 1 | 2 | 3 |
    |----|----|----|---|---|---|---|
    | f(x)| 5  | 2  | 1 | 2 | 5 | 10|
    
    Find: f(-1), f(2), f(0), and solve f(x) = 5

11. If g(2) = 7, g(-1) = 4, and g(0) = -2, find:
    - The value of x where g(x) = 7
    - The value of g(-1) + g(0)
    - True or false: g is a function

## Day 2 Exercises: Function Transformations

### Identifying Transformations (25 problems)

**Vertical Shifts**
12. Describe how each function transforms f(x) = x²:
    - g(x) = x² + 3
    - h(x) = x² - 5
    - k(x) = x² + 1/2
    - m(x) = x² - 10

**Horizontal Shifts**
13. Describe how each function transforms f(x) = x²:
    - g(x) = (x - 4)²
    - h(x) = (x + 2)²
    - k(x) = (x - 1/2)²
    - m(x) = (x + 7)²

**Vertical Stretches and Compressions**
14. Describe how each function transforms f(x) = |x|:
    - g(x) = 3|x|
    - h(x) = (1/2)|x|
    - k(x) = -2|x|
    - m(x) = -(1/4)|x|

**Horizontal Stretches and Compressions**
15. Describe how each function transforms f(x) = √x:
    - g(x) = √(2x)
    - h(x) = √(x/3)
    - k(x) = √(4x)
    - m(x) = √(x/2)

**Combined Transformations**
16. Describe all transformations needed to go from f(x) = x² to:
    - g(x) = 2(x - 3)² + 1
    - h(x) = -(x + 1)² - 4
    - k(x) = (1/3)(x + 2)² + 5
    - m(x) = -2(x - 1)² + 3

17. **Matching Exercise**: Match each function with its transformation description:
    
    Functions:
    - A) f(x) = (x + 1)² - 3
    - B) f(x) = 2x² + 4
    - C) f(x) = -(x - 2)²
    - D) f(x) = (1/2)x²
    
    Transformations:
    - 1) Reflection over x-axis, shift right 2
    - 2) Vertical stretch by 2, shift up 4
    - 3) Vertical compression by 1/2
    - 4) Shift left 1, shift down 3

### Graph Sketching (15 problems)

18. Given the parent function f(x) = x², sketch:
    - g(x) = (x - 2)² + 1
    - h(x) = -(x + 1)² + 3
    - k(x) = 2x² - 4

19. Given the parent function f(x) = |x|, sketch:
    - g(x) = |x - 3| + 2
    - h(x) = -|x + 1| - 1
    - k(x) = 3|x| + 1

20. Given the parent function f(x) = 1/x, sketch:
    - g(x) = 1/(x - 2) + 1
    - h(x) = -1/(x + 1)
    - k(x) = 2/x - 3

## Day 3 Exercises: Advanced Function Analysis

### Function Composition (20 problems)

21. Given f(x) = 2x + 1 and g(x) = x² - 3, find:
    - (f ∘ g)(x)
    - (g ∘ f)(x)
    - (f ∘ g)(2)
    - (g ∘ f)(-1)

22. Given f(x) = √x and g(x) = x + 4, find:
    - (f ∘ g)(x) and its domain
    - (g ∘ f)(x) and its domain
    - (f ∘ g)(5)
    - (g ∘ f)(9)

23. Given h(x) = 1/x and k(x) = x - 2, find:
    - (h ∘ k)(x) and its domain
    - (k ∘ h)(x) and its domain
    - Values of x where (h ∘ k)(x) is undefined

**Decomposition Problems**
24. Express each function as a composition f(g(x)):
    - H(x) = √(x + 3)
    - K(x) = (2x - 1)³
    - M(x) = |x² - 4|
    - N(x) = 1/(x + 5)²

### Inverse Functions (15 problems)

25. Determine if each function has an inverse. If so, find it:
    - f(x) = 3x - 7
    - g(x) = x² + 2 (for x ≥ 0)
    - h(x) = 1/(x - 1)
    - k(x) = √(x + 4)

26. **Verification Problems**: Verify that the functions are inverses:
    - f(x) = (x - 2)/3 and g(x) = 3x + 2
    - f(x) = x³ + 1 and g(x) = ∛(x - 1)
    - f(x) = 2/x and g(x) = 2/x

### Piecewise Functions (10 problems)

27. Evaluate the piecewise function:
    ```
    f(x) = { 2x + 1    if x < 0
           { x²        if 0 ≤ x ≤ 2
           { 2x - 3    if x > 2
    ```
    Find: f(-2), f(0), f(1), f(3), f(-1)

28. **Continuity Analysis**: Determine where the following function is continuous:
    ```
    g(x) = { x + 1     if x < 1
           { 3         if x = 1
           { x²        if x > 1
    ```

## Day 4 Exercises: Limits and Continuity

### Basic Limits (30 problems)

**Direct Substitution Limits**
29. Evaluate each limit:
    - lim(x→3) (2x + 5)
    - lim(x→-1) (x² - 3x + 2)
    - lim(x→2) (x³ + x - 1)
    - lim(x→0) (sin(x) + cos(x))

**Factoring Required**
30. Evaluate each limit:
    - lim(x→2) (x² - 4)/(x - 2)
    - lim(x→3) (x² - 9)/(x - 3)
    - lim(x→-1) (x² + 3x + 2)/(x + 1)
    - lim(x→4) (x² - 16)/(x - 4)

**Rationalizing Required**
31. Evaluate each limit:
    - lim(x→0) (√(x + 1) - 1)/x
    - lim(x→4) (√x - 2)/(x - 4)
    - lim(x→0) (√(x + 9) - 3)/x
    - lim(x→1) (√(x + 3) - 2)/(x - 1)

**Trigonometric Limits**
32. Evaluate each limit:
    - lim(x→0) sin(x)/x
    - lim(x→0) (1 - cos(x))/x
    - lim(x→0) sin(3x)/x
    - lim(x→0) tan(x)/x

**Limits at Infinity**
33. Evaluate each limit:
    - lim(x→∞) (3x² + 2x)/(x² + 1)
    - lim(x→∞) (2x + 1)/(x² + 3)
    - lim(x→∞) (x³ - x)/(2x³ + 5)
    - lim(x→-∞) (4x² + x - 1)/(2x² + 3x)

### One-Sided Limits (15 problems)

34. Given the function:
    ```
    f(x) = { x + 2     if x < 1
           { 3         if x = 1
           { x²        if x > 1
    ```
    Find:
    - lim(x→1⁻) f(x)
    - lim(x→1⁺) f(x)
    - lim(x→1) f(x)
    - Is f continuous at x = 1?

35. Evaluate the one-sided limits:
    - lim(x→0⁺) 1/x
    - lim(x→0⁻) 1/x
    - lim(x→2⁺) (x - 2)/|x - 2|
    - lim(x→2⁻) (x - 2)/|x - 2|

### Continuity Problems (20 problems)

36. **Three-Part Definition**: For each function, use the three-part definition to determine continuity at the given point:
    - f(x) = (x² - 1)/(x - 1) at x = 1
    - g(x) = |x - 2| at x = 2
    - h(x) = sin(x)/x at x = 0 (where h(0) = 1)

37. **Find the Value**: Find the value of k that makes each function continuous:
    ```
    f(x) = { 2x + 3    if x ≤ 1
           { kx + 1    if x > 1
    ```
    
    ```
    g(x) = { x² - 1    if x ≠ 2
           { k         if x = 2
    ```

38. **Interval of Continuity**: State the intervals where each function is continuous:
    - f(x) = 1/(x - 3)
    - g(x) = √(x - 1)
    - h(x) = (x² - 4)/(x + 2)
    - k(x) = tan(x)

## Day 6 Exercises: Real-World Applications

### Modeling Problems (20 problems)

45. **Projectile Motion**: A ball is thrown upward from a height of 6 feet with initial velocity 48 ft/s. The height function is h(t) = -16t² + 48t + 6.
    - When does the ball reach its maximum height?
    - What is the maximum height?
    - When does the ball hit the ground?
    - What is the ball's height after 2 seconds?

46. **Cost Functions**: A company has fixed costs of $500 and variable costs of $12 per item.
    - Write the total cost function C(x)
    - Write the average cost function A(x) = C(x)/x
    - Find the cost of producing 100 items
    - What happens to average cost as production increases?

47. **Population Growth**: A bacteria population grows according to P(t) = 100e^(0.2t), where t is in hours.
    - What is the initial population?
    - What is the population after 5 hours?
    - How long until the population reaches 1000?
    - What is the growth rate percentage?

48. **Revenue and Profit**: A company sells x items at price p = 50 - 0.1x dollars each.
    - Write the revenue function R(x)
    - If the cost function is C(x) = 200 + 5x, write the profit function P(x)
    - Find the number of items that maximizes profit
    - What is the maximum profit?

### Applied Function Analysis (15 problems)

49. **Temperature Conversion**: 
    - Express Celsius as a function of Fahrenheit
    - Express Kelvin as a function of Celsius
    - Find the temperature where Celsius equals Fahrenheit

50. **Geometric Applications**: 
    - Express the area of a circle as a function of its diameter
    - Express the surface area of a cube as a function of its volume
    - Express the area of an equilateral triangle as a function of its perimeter

51. **Physics Applications**:
    - Express kinetic energy as a function of velocity (KE = (1/2)mv²)
    - Express gravitational force as a function of distance (F = GMm/r²)
    - Express the period of a pendulum as a function of its length

## Day 7 Exercises: Review and Assessment

### Comprehensive Review (25 problems)

52. **Mixed Practice**: Given f(x) = x² - 4x + 3 and g(x) = 2x + 1:
    - Find f(3) and g(-2)
    - Find (f ∘ g)(x) and (g ∘ f)(x)
    - Find the domain of f and g
    - Solve f(x) = 0

    - g(x) = 2(x + 1)³ - 4
    - h(x) = -(x - 3)³ + 2
    - k(x) = (1/2)(x + 2)³ + 1

54. **Limit Challenge**: Evaluate:
    - lim(x→∞) (√(x² + x) - x)
    - lim(x→0) (sin(2x) - 2sin(x))/(x³)

### Problem-Solving Applications (15 problems)

55. **Optimization**: A farmer has 200 feet of fencing to enclose a rectangular field adjacent to a river (no fence needed along the river). Express the area as a function of the width, then find the dimensions that maximize the area.

56. **Related Functions**: If the profit function is P(x) = -x² + 50x - 200:
    - Find break-even points (where P(x) = 0)
    - Find the production level that maximizes profit
    - Express profit as a function of revenue if cost is C(x) = x² - 50x + 200

57. **Function Investigation**: Given that f(x) passes through (2, 5) and f(x + 3) = f(x) + 6 for all x:
    - Find f(5), f(8), and f(-1)
    - What type of function could f be?
    - Write a possible formula for f(x)

### Self-Assessment Quiz (10 problems)

58. **True or False** (justify your answers):
    - Every function has an inverse
    - If lim(x→c) f(x) exists, then f is continuous at x = c
    - The function f(x) = x² has a horizontal asymptote
    - Vertical shifts change the domain of a function
    - If f(a) is undefined, then lim(x→a) f(x) does not exist

59. **Multiple Choice**: The function g(x) = f(2x - 4) + 3 represents which transformations of f(x)?
    - A) Right 4, up 3
    - B) Right 2, up 3
    - C) Horizontal compression by 1/2, right 2, up 3
    - D) Horizontal compression by 2, right 4, up 3
